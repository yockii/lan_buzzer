# LAN Buzzer - Quiz Mode Edition

局域网抢答/答题系统 - 支持 5-10 人实时抢答和题库答题

## 🆕 题库模式功能

这是 **feature/question-bank** 分支，在基础抢答功能之上，新增了完整的题库答题模式。

### 功能特点

- 🎯 实时抢答，毫秒级响应
- 👥 支持 5-10 人同时参与
- 💻 电脑、手机均可使用
- 🎨 颜色标识，支持重名
- ⚡ 单文件运行，无需安装依赖
- 🔒 局域网通信，安全可靠
- ✨ **题库支持，自动轮流出题**
- 🤖 **自动判断单选题和判断题**
- 👆 **主持人可手动覆盖任何答案**
- 👑 **自动显示最先答对的选手**
- 📊 **3列优化布局，适合投屏**
- 🔄 **题目去重，避免重复**

## 游戏模式

系统支持两种模式，根据是否存在 `questions.txt` 文件自动切换：

### 抢答模式（默认）
传统抢答系统，选手抢答看谁手速快。

### 答题模式（题库模式）
当存在 `questions.txt` 文件时，系统自动进入答题模式。

## 📚 题库使用指南

### 1. 创建题库文件

在 `lan-buzzer.exe` 同目录下创建 `questions.txt` 文件。

### 2. 题库格式

题库使用管道符（`|`）分隔的文本格式：

#### 单选题
```
[单选]
什么是CPU?|A.中央处理器|B.显卡|C.内存|D.硬盘|A
下列哪个是编程语言？|A.HTML|B.Python|C.JPG|D.MP3|B
```

#### 判断题
```
[判断]
地球是圆的|对
太阳从西边升起|错
```

#### 问答题
```
[问答]
中国的首都在哪里？|北京
一年有多少个月？|12个
```

### 3. 格式说明

- **题型标识**：`[单选]`、`[判断]`、`[问答]` 必须单独一行
- **分隔符**：使用管道符 `|` 分隔各个字段
- **单选题格式**：`问题|选项A|选项B|选项C|选项D|答案`
  - 答案只需填选项字母（如 `A`）或完整选项（如 `A.中央处理器`）
- **判断题格式**：`问题|答案`
  - 答案为 `对` 或 `错`
- **问答题格式**：`问题|答案`
  - 答案为自由文本
- **空行**：题目之间可以有空行，系统会自动忽略

### 4. 答案匹配规则

系统采用**模糊匹配**，自动忽略：
- 标点符号：。！？，、；：""''（）.,!?;:"'()
- 空白字符：空格、制表符、换行符
- 语气助词：的、了、着、啊

例如：
- 题库答案：`北京`
- 用户回答：`北京市`、`北京的` → ✅ 判定为正确

### 5. 答题流程

1. **启动程序**：运行 `lan-buzzer.exe`
2. **主持人操作**：
   - 点击"开始答题"按钮
   - 系统随机抽取一道未答过的题目
   - 所有选手看到题目
3. **选手答题**：
   - 单选/判断题：点击选项
   - 问答题：输入答案并提交
4. **自动判断**（单选/判断题）：
   - 系统自动判定答案对错
   - 绿色 ✓ 表示正确
   - 红色 ✗ 表示错误
5. **手动覆盖**（所有题型）：
   - 主持人点击选手答案可切换状态
   - 黄色待定 → 绿色正确 → 红色错误 → 黄色待定
   - 适用于纠正误判或判定问答题
6. **胜出判定**：
   - 系统自动显示最先答对的选手 👑
   - 当主持人修改答案时，胜出者会自动更新
7. **下一题**：
   - 点击"下一题"按钮
   - 系统随机抽取下一道题
   - 之前题目的答案会被清空

### 6. 主持人界面功能

#### 控制按钮
- **开始答题**：开始新题目
- **下一题**：
  - 如果有未判定的答案，会弹出确认提示
  - 清空上一题的答案
  - 随机抽取下一道题
- **重置题库**（左上角小按钮）：
  - 清空所有题目的"已答"标记
  - 从头开始重新出题
  - 需要确认操作

#### 顶部栏
- **收起/展开**：点击左上角 `◀/▶` 按钮收起顶部栏
  - 收起后只显示：切换按钮 + 重置按钮
  - 节省屏幕空间，更适合投屏
- **IP 选择**：多网卡环境下选择合适的 IP
- **二维码**：选手扫码加入

#### 选手列表（左右两侧）
- 显示选手颜色、姓名、设备类型
- 实时显示答题状态和答案内容
- 点击答案可手动修改判定状态

#### 题目显示（中间区域）
- 大字体显示题目
- 单选/判断题：显示所有选项
- 问答题：提示"选手输入答案"

### 7. 题库管理

#### 题目去重
- 系统自动记录已答过的题目
- 随机抽题时避免重复
- 所有题目答完后显示："✅ 所有题目已完成！"

#### 重置题库
- 点击左上角"重置题库"按钮
- 确认后清空已答记录
- 可以从头开始重新答题

#### 添加/修改题目
1. 关闭程序
2. 编辑 `questions.txt` 文件
3. 保存文件
4. 重新运行程序

## 使用方法

1. 下载 `lan-buzzer.exe`（Windows）或 `lan-buzzer`（Linux/Mac）
2. （可选）在同一目录创建 `questions.txt` 题库文件
3. 双击运行程序
4. 浏览器自动打开主持人界面
5. 选手通过二维码或 URL 加入
6. 开始游戏！

## 系统要求

- Windows 10+ / Linux / macOS
- 同一 Wi-Fi 局域网
- 现代浏览器（Chrome、Firefox、Safari）
- **无需互联网连接**（二维码本地生成）

## 技术栈

- 后端: Go 1.25+ + Fiber v2 + WebSocket
- 前端: Vue 3 + TypeScript + TailwindCSS
- 二维码: qrcode.js（本地生成，无外部依赖）
